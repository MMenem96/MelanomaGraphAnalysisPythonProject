How It Works

Our system uses advanced feature engineering to differentiate between BCC (Basal Cell Carcinoma) and BKL (Benign Keratosis-like Lesions).

Image Preprocessing

Hair removal using morphological operations and Gaussian filtering for noise reduction and feature enhancement.

Feature Extraction

Extract 500+ features: Color statistics, texture (GLCM, LBP), geometric properties, and Multi-Parameter Krawtchouk moments.

Machine Learning Classification

Advanced ensemble and gradient boosting models trained to distinguish BCC from BKL with high accuracy.
